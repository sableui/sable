# Motion needs a reason

Editorial reference audits found shared entrance timelines, small travel, and
slower media transitions. Technical tool audits found short ease-out feedback and
no overshoot. Copying one grammar into the other loses the purpose that made it
work.

For each meaningful change, record trigger, user benefit, driver, duration/ease,
interruption behavior, and reduced-motion result. Feedback confirms an action;
spatial motion can explain where content went; activity distinguishes waiting
from failure. Initial reading content can paint immediately. A deliberate static
choice is valid when no information is gained by animation.

Use Sable's motion tokens and primitives where they express that decision. Custom
CSS and external animation drivers must also honor the motion policy. Inspect a
real state change and reduced-motion mode; a resting screenshot cannot establish
timing, interruption behavior, or that content remains available.

Provenance: distilled from the contrasting calm editorial and dense technical
reference audit grammars. Timing numbers in an old audit are observations, not
mandatory new defaults. Retrieve `sable learn --show motion-needs-a-reason --json`.
