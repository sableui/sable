# Hierarchy is a relationship

Prior builds picked real `text-title-*` utilities for feature titles
whose role in the composition was closer to a display heading. Every token was
valid; the hierarchy still flattened. Another build reproduced a measured 128px
display size inside a narrower container, turning roughly three lines into six.

Choose the semantic HTML heading level separately from its visual tier. Set the
text, available measure, tier, weight, and adjacent spacing together, then inspect
the rendered line count on desktop and mobile. If the phrase is factual or
approved, change the layout before rewriting it. Load the actual font before
judging the result; fallback metrics are different.

Transfer this to display-led reading and persuasion surfaces. In an operating
tool, task hierarchy and scan speed may call for smaller type and consistent rows.
Large type and light weight are possible choices, never a universal recipe for
quality.

Provenance: distilled from the Sable build pipeline's recorded
typography and line-wrap defects. This is a curated precedent, not a fresh visual
test of the current package. Retrieve the structured record with
`sable learn --show hierarchy-is-a-relationship --json`.
