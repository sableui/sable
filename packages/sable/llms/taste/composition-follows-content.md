# Composition follows content

Mixed-width feature audits gave primary ideas more space. The reusable decision
is that emphasis follows the importance and shape of the content. A particular
7/5 grid is only one implementation.

Write the section's job before choosing its container. A comparison needs shared
baselines; a sequence needs order; a single artifact benefits from uninterrupted
space; subordinate facts can live in a ruled list. A card earns its edge when it
groups a distinct object or interactive destination. Space can group text without
a container.

Inspect the whole page at reduced scale. If every section has the same silhouette,
check whether the content actually has the same job. Vary width or density when
the story changes, while keeping alignment anchors and a small spacing vocabulary.
Preserve predictable repetition for equivalent records, forms, and frequent tasks.

Provenance: distilled from the bundled mixed-width feature pattern and editorial
reference audits. This is conditional precedent, not evidence that asymmetry is
always better. Retrieve `sable learn --show composition-follows-content --json`.
