# Art direction — prism

Style vocabulary derived from prism.io's illustration devices (bento-card illustrations, hero gradient panel, pricing dot-grid ornament). Style only — subject matter is always composed fresh per build.

- **Mood:** serene, precise, techno-optimist, softly luminous, clinical-but-warm.
- **Texture/material:** smooth airbrushed gradient fields (pink -> violet -> periwinkle) as backdrops; crisp flat vector UI surfaces floated on top; fine particle/dot texture; occasionally one glossy 3D-render material with soft sheen.
- **Lighting/shading:** diffuse, sourceless glow within gradients; illustration layers flat with no cast shadows or only the faintest ambient lift; no hard cel shading.
- **Line/geometric language:** thin uniform strokes; tidy rectangular panels with small radii echoing the UI's 8px card radius; isometric arrangement for system diagrams; dot/particle grids as a recurring geometric motif.
- **Recurring effects:** long soft mesh gradients, particle/dot fields, subtle glow; no grain, halftone, or duotone.
- **Color usage in illustrations (diverges from UI chrome):** the interface chrome stays strictly monochrome (white / near-black / gray) — illustrations carry nearly all chroma: a pink-violet-periwinkle gradient family plus one vivid indigo accent (~oklch(55% 0.2 282)) inside mock UIs; standalone feature tiles may break into saturated brand colors (chartreuse, mint, pink). Color is quarantined to imagery; never let it bleed into page chrome.
